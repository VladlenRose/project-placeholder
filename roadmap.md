# Roadmap

Текущие задачи:
- [ ] Оформление торгов: таблица параметров, роли, крупнее шрифт, нумерация и цвета
- [ ] Естественные интервалы и краткий итог со свёрнутым полным разговором
- [ ] Общее предложение каждого участника после подтверждения пунктов; автоматическое оформление договора после обоих предложений
- [x] Исправить ошибку входа при открытии переговоров — обновлено подключение, под аккаунтом участника открыт существующий торг и прочитана версия 1
- [x] Исправить создание карточки с фото — создано хранилище, проверены товар и услуга с фото
- [x] Удаление товаров и услуг с сохранением заявок и торгов — проверено удаление и сохранение копий характеристик
- [x] Имя из регистрации у заявок при отсутствии заполненного профиля — проверено в профиле и истории заявок
- [x] Имена и профили участников у заявок; открытие карточки вместо создания заявки
- [x] Восстановление пароля письмом на почту
- [ ] Проверка получения письма и смены пароля по ссылке — нужна реальная почта; тестовый адрес отклонён почтовой службой
- [x] Удаление торгов администратором и проверка поведения удаления связанных заявок
- [x] Светофор и процент после торга по параметрам, отдельное согласие людей перед договором
- [x] Развёрнутый торг с удержанием условий по приоритетам и сохранением результатов
- [x] Небольшой тестовый каталог: 5 товаров/услуг, 25 покупок владельца и 25 продаж указанного тестового участника
- [x] Чат-переговоры переделаны под заявки (детерминированный подбор + ИИ для текста)
- [x] Голосовой ввод текста заявки
- [x] Сохранять торг по параметрам после перезагрузки, вторая сторона видит предложения и подтверждения
- [x] Карточки параметров: изменение значений, новый торг и подтверждение встречного предложения
- [x] Согласие каждого участника на текущую версию условий
- [x] Запрет повторного торга по одной паре заявок (уже обеспечен уникальностью в базе)
- [x] Пересчёт торга: приоритет = мера удержания/уступки, авто-принятие более выгодных условий, выгода сторон по каждому параметру
- [x] Ориентир по похожим заявкам под каждым параметром формы (подсказка, не меняет условия)
- [x] Автозапуск торга ботов при «Поиск соответствий»
- [ ] Чат между людьми и подписание согласия обеими сторонами

Отдельный свободный чат с агентом пока не сохраняется. Договор сохраняется как неподписанный черновик согласованных условий; юридическое оформление и подписание — следующий этап.
